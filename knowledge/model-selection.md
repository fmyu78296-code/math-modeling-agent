# 模型选择
先判断目标、规模、依赖、单位、约束、解释需求及预算，关键词只供检索。
| 类型 | 基线 | 候选和检验 |
|---|---|---|
| 时序 | 持平/季节朴素 | 趋势、指数平滑、ARIMA；滚动验证与周期证据 |
| 表格预测 | 均值/线性 | 树集成；分组/时间划分、训练内预处理 |
| 分类 | 多数类/逻辑回归 | 树模型；不平衡指标与验证阈值 |
| 评价 | 等权 | AHP/TOPSIS；方向、重复计权、权重敏感性 |
| 聚类 | 简单分组 | K-means/密度聚类；距离尺度和稳定性 |
| 优化 | 可行规则 | LP/MILP/非线性；先数学化，检查可行性和界 |
| 路径调度 | 贪心 | 图算法/整数规划；连通、容量、时间窗 |
| 动力系统 | 机理近似 | ODE/仿真；守恒、量纲、初边值、步长 |
| 随机系统 | 确定性近似 | Monte Carlo；种子、区间、尾部风险 |
至少比较基线和一个候选。验证选型后冻结，再评估测试集。
