# 知识库

`model-selection.md` 是方法指南，`cards/linear-trend.md` 是自建教学卡。它们的结论强度和适用条件以文件中的证据为准。

本地文献按 `refs/README.md` 建立 `refs/catalog.csv`；上传版索引初始为空。`sources.csv` 是通用来源登记表头。

新研究按 `templates/literature-card.md` 和 `templates/literature-evidence.md` 保存。researcher 写入 `knowledge/runs/<task_id>/`，总控验收后再合入共享知识库。
