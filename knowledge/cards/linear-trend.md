# 一元趋势回归
输入时间 t、观测 y，最小化 sum(y-a-bt)^2。b=sum((t-tbar)(y-ybar))/sum((t-tbar)^2)，a=ybar-b*tbar。
至少两个不同时间点且值有限；b 的单位为 y单位/时间单位。复杂度 O(n)，代码 algorithms/linear.py。
实现会先按输入量级缩放再计算均值、协方差、MAE 和 RMSE，以避免中间平方或求和溢出。布尔值、非数值、非有限值和畸形行统一拒绝；如果最终斜率、截距、预测或误差超出 Python 有限浮点数可表示范围，则明确报错。
