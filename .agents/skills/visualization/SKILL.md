# visualization

## 输入和执行边界
按 AGENTS.md 选择任务范围；局部修订一张图只处理那张图。正式分派的图表子任务从项目根读取 docs/protocol.md 和任务 JSON，确认上游产物，只写 task output_dir，不自行创建 Agent。绘制拟放入论文的图时读取[论文配图指南](references/paper-figures.md)，先确定模板的实际正文宽度、图在论文中要回答的问题和最终插入位置；以下输出均相对 output_dir。

## 执行步骤
1. 读取核验的指标、预测或解轨迹，先写出图的唯一目的和数据来源，再选分布、趋势、残差、混淆矩阵、收敛、敏感性、Pareto、调度等合适图形。正文图应承担解释或比较；大量同构曲线优先做可读的分面比较，次要细节入附录。
2. 绘图代码按目标栏宽设置画布与纵横比，统一字号、线型、颜色、单位和刻度；多面板使用一致坐标与 (a)(b)… 标识。图例不遮挡数据，图内不用长标题代替图题，灰度打印也应能区分类别。具体代码与 Word/LaTeX 导出方式见[论文配图指南](references/paper-figures.md)。
3. 坐标尺度与截断必须诚实；实际与预测、训练与测试用清楚编码区分，不能混成一条曲线。置信带、误差棒和显著性标记只有在确有计算依据时才绘制；阴影含义与样本数在图题中交代。
4. 论文图优先同时导出 PDF/SVG 矢量版与按最终尺寸生成的清晰 PNG，检查中文字体和数学符号；不能用截图代替绘图输出。最终文稿中保持纵横比，把图放在首次讨论附近并用正文解释。
5. 每图记录输入文件/哈希、生成代码和命令、坐标与单位、样本范围、模型与数据划分、输出路径。在最终文稿 PDF 的实际插入尺寸检查一次裁切、重叠、缺字和文字过小；失败只修复受影响图并复查。
6. 生成 figure_manifest.json，使论文中每一图对应真实数据与代码。无运行轨迹不能伪造收敛图；图像美观不能掩盖数据缺口。

## 输出与验收
完整图表任务交付 figures/、figure_manifest.json 和可重跑的绘图代码，记录输入来源、处理规则、实际命令与未完成项。局部任务只交付被要求的图及其代码/来源，不制造无关图表。正式子任务按协议向总控返回真实状态；无关键输入时返回 blocked。
