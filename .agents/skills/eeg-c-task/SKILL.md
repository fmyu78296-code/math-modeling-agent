# eeg-c-task

## 输入和执行边界
先读 docs/protocol.md、当前任务 JSON、C 题原文及四个 MAT 附件；本 Skill 是题目专用补充，须与 problem-analysis、data-processing、mathematical-modeling 和 experiment-analysis 配合。只写任务 output_dir，不改 competition/input/，不自行创建 Agent。以下产物路径均相对 output_dir。题面、附件、实际字段若不一致，以核实后的原始材料为准并记录差异，不把本文件当作替代题面。

## 执行步骤
1. 逐个核验 `VisualCogA_Task-1.mat`、`VisualCogA_Task-2.mat`、`VisualCogB_Task-1.mat`、`VisualCogB_Task-2.mat` 的数组结构、长度、缺失、时间戳、采样间隔与题面 256 Hz 是否相符。区分 Task-1/Task-2；在元数据确认前不臆断 A/B 一定代表被试、会话或实验条件。
2. 建立通道契约：题面给出的 1–3 为 Fz、F3、F4 原始脑电；4–6 为机器自带处理结果，按题面要求不直接用于建模或作为去噪结果的捷径；7 标为 ECG，题面称用于参考；8 为视觉提示（−1 左、+1 右），9 为目标应答（−2 左、+2 右），10 为时间戳。核对真实文件中的顺序、类型和事件编码；若发现差异先停下核查。
3. 从时间戳和事件变化构建逐试次索引，记录实际可观察的视觉提示与应答时间；目标出现时间若无独立标记只能估计并注明依据。区分提示方向、实际应答、应答正确性和缺失/迟延应答；不能用应答反推视觉提示标签，也不能把题面约 0.5 s、0.2 s、2 s 当成精确事件时间。
4. 预先定义分析窗、刺激前基线和伪影规则。比较原始信号、简单基线去噪和候选方法，报告保留/剔除试次数、波形改变、左/右可分辨信息及跨试次稳定性。检查边界效应、滤波相位或时延、过度平滑；不能仅以图像更平滑宣称“保留了视觉特征”。P300 的典型时间窗可作为文献支持的候选，不把它当成每个 Fz/F3/F4 试次都有的已证事实。
5. 先定义试次、连续时间块、文件和可能的被试/会话层级，再按可证实层级划分训练、验证和测试。去噪参数、归一化、特征选择和模型调参只能在训练部分拟合；重叠窗口、同一试次切片和相邻信息不得跨集合泄漏。样本或被试数量不足时只报告当前层级结果，不宣称跨人群泛化。
6. 逐问对应题面：Task-1/Task-2 的视觉响应提取与曲线拟合；左/右三角刺激的可区分特征；从视觉通路到头皮观测的机理模型；认知阶段模型及应答错误/缺失的处理。每个模型说明可观测量、潜变量、识别假设和可检验预测。仅凭三路额部头皮信号无法唯一确定 LGN、海马或皮层深部来源；把源位置与疾病诊断相关论断标为假说或外部文献背景，不能写成本题数据直接证实。
7. 记录每项图表和结论的原始文件、通道、试次集合、时间窗、处理版本、随机种子及运行命令。用同一固定评估方案比较方法；保留失败、排除和不确定性，不把医学应用前景写成已验证的临床效果。

## 输出与验收
交付 `c_data_contract.md`、`trial_index.csv`、`preprocessing_comparison.csv`、`signal_validation.md`、`mechanism_identifiability.md`；若当前 acceptance 只覆盖部分问题，可交对应子集并明确未完成项。`trial_index.csv` 至少包含原始文件、试次 ID、提示方向、应答状态、事件时间、切分归属与排除原因；比较表需含方法、保留试次、实际验证指标及配置路径。用真实命令核对事件计数、通道使用与无泄漏；缺关键字段、事件无法对齐或题面冲突时按协议返回 partial/blocked。按 docs/protocol.md 记录产物哈希、命令和局限，未运行的验证不得标为完成。
