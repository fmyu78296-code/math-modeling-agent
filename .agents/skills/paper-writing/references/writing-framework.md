# 数学建模竞赛论文的论证框架

本文件帮助整篇论文或重要章节的实质性写作。版式、封面、摘要页和引用格式以当届官方格式规范与模板为准；这里的章节顺序可随题目调整。2026 年竞赛公告要求使用附件 2 的格式规范和附件 3 的模板，摘要概括建模思路、主要方法、模型、结果与结论及创新点；不要把本文件当作官方版式规定。来源：[2026 年开赛公告及附件入口](https://www.cmathc.org.cn/cpmcm/news/642.html)、[官方附件 2](https://cpipc.acge.org.cn/sysFile/downFile.do?fileId=97a93e3a9e074738aea95eea986508f2)。

## 从证据组织论证

先把每个问题写成一条可追溯链：题目要回答什么 → 数据与约束是什么 → 为什么选择该模型 → 核心公式与算法如何运行 → 实际得到什么 → 与基线/备选相比如何 → 结果的适用范围。正文中的重要段落尽量具备“明确判断—依据或推导—可定位的结果—对题目的含义”；不要求机械套句式。若链中某环缺失，写明未验证处或补做必要实验，不用空泛文字填充。

摘要最后写：开头点出对象和目标；逐问各用一两句说明有区分度的方法与最重要的实测结果；最后说明可信的贡献与边界。数值带单位、数据范围和评价口径。摘要避免只列算法名、无结果的“效果显著”、正文没有证据的创新点。

正文建议包含下列功能，标题可按题目重组：

| 功能 | 应回答的读者问题 | 有效的内容 |
|---|---|---|
| 问题分析与路线 | 三问各要交付什么、彼此如何依赖？ | 逐问输入/输出/评价标准和一张简明依赖图；不长篇复述题面 |
| 数据与假设 | 数据是什么、可靠到什么程度？ | 样本/单位/事件或约束审计、缺失与异常、划分、假设的理由和影响 |
| 模型建立 | 变量和方程为何这样定义？ | 从题意或机理推导关键方程、目标及约束；解释参数与可辨识性，省略无关教科书公式 |
| 求解实现 | 读者如何复现？ | 算法流程、参数估计、初值/边界、终止条件、实际运行设置及必要伪代码 |
| 结果解释 | 模型回答了什么？ | 核心数值、表图、与基线对照、误差和异常；解释趋势而非复述图上每个点 |
| 检验与讨论 | 结论是否可靠，何时失效？ | 留出数据或硬约束检验、消融/敏感性在已运行时报告、负结果、失效条件与实际限制 |
| 结论与推广 | 每问最终答案是什么？ | 可被前文追溯的逐问结论、实用意义及需额外数据才能验证的推广 |

每问内部通常写“问题与方法选择 → 关键模型/求解 → 结果 → 比较/检验 → 小结与下问接口”。共享的数据处理、符号和验证设计放在公共章节，避免三问各重复一遍。图、表、公式在首次讨论附近放置；先用正文说明读者应看什么，再用图题交代对象/条件/单位/样本，随后解释观察和局限。大表、重复曲线、冗长推导可入附录，但核心答案和负结果留在正文。

## 约 30 页的篇幅安排

当前用户希望约 30 页。以下仅是按官方模板导出 PDF 后的**起步预算**，不是竞赛规定，也不是各节最低字数：封面 1 页、摘要 1 页、问题分析 2 页、数据与假设 3 页、问题一 5 页、问题二 6 页、问题三 5 页、统一检验与讨论 3 页、结论及参考文献 2 页、必要附录 2 页，合计约 30 页。根据真实题目和证据移动篇幅，优先保证逐问回答、模型可复现和结果可解释；若现有成果撑不起某节，保留较短且诚实的草稿并列出缺口，不用重复插图或扩写背景凑页。

## 让内容丰盈的编辑方法

- 对一条模型选择，补足它解决的具体困难、采用前提、与基线差异以及数据是否支持；不要只写“采用某先进算法”。
- 对一条结果，交代比较对象、样本/时间范围、指标定义、数值大小及不确定性，再说明为何有用或为何不足；不要只写“由图可知效果较好”。
- 对公式，说明变量的现实含义、关键假设、来源或推导、参数估计办法及与代码的对应；大量机械代数放附录。
- 对文献，引用其实际支持的事实或方法，并说清迁移到本题需要哪些额外假设；不以参考文献数量替代论证。
- 对弱结果，分析可能的数据、模型和评估原因，区分已观察到的失败与尚未测试的猜想；不改写指标口径使其看起来更好。
- 对“创新”，写实际改变了什么、为何必要、由哪项对照或推导支持；新颖措辞不等于方法贡献。

编辑一次完整初稿后只做一次按题目覆盖、数字/引用对应、图表可读性和逻辑衔接的针对性检查；修复发现的问题后复查受影响处。另有最终候选包时再按项目独立审阅流程执行。
